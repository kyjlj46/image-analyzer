이미지 분석 에이전트

LangGraph 에이전트가 이미지를 동시에 분석하고, 스스로 검토하고, 웹으로 사실을 확인한 뒤 종합 리포트와 .txt 문서를 만듭니다. 분석 후에는 이미지에 대해 추가로 질문할 수 있습니다.

이미지를 끌어다 놓거나 클릭해서 선택
JPEG · PNG · GIF · WEBP · 장당 5MB · 최대 10장 · Ctrl+V 붙여넣기
동시 처리여러 장을 한 번에 분석할 개수
흐름: 유형 판별 → 분석 → 검토 → 웹 검증·웹서칭(동시) → (여러 장이면) 종합 리포트
단계마다 Claude를 호출하므로 켜는 단계가 많을수록 시간이 더 걸립니다.
이미지를 올리고 분석을 시작하세요.
결과가 여기에 탭으로 표시됩니다.
